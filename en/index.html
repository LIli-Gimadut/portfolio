EdTech · AI delivery

A learner assistant for a school LMS

Challenge
Build an assistant into the learning platform to answer students’ questions.
My role
I agreed on requirements and scope with the CPO. I used AI tools to prototype the assistant and implement retrieval-augmented generation (RAG), so it could find relevant information and use it as context when generating answers. I tested user scenarios and addressed cases where the assistant gave off-topic answers.
Result
I ran a pilot, reviewed feedback, made revisions and rolled the assistant out to all platform users.
